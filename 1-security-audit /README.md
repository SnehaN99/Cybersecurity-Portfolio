# Internal Security Audit – Botium Toys

## Objective
Conducted an internal security audit for a fictional company 
(Botium Toys) as part of the Google Cybersecurity Certificate program.

## What I Did
- Reviewed the company's scope, goals, and risk assessment report
- Completed a controls and compliance checklist
- Identified gaps in controls (least privilege, IDS, encryption, etc.)
- Assessed compliance with PCI DSS, GDPR, and SOC standards

## Key Findings
- Risk score: 8/10 (High)
- Missing critical controls: encryption, IDS, disaster recovery, backups
- Non-compliant with PCI DSS (no encryption on card data)
- GDPR partially met (72hr notification plan exists)

Security auditing · NIST CSF · Risk assessment · 
Compliance (PCI DSS, GDPR, SOC) · Controls assessment
